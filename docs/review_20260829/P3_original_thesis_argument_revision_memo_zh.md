# P3 原始命题与论证方案修改备忘录

日期：2026-08-29  
性质：只读作者审阅备忘录；不修改 manuscript

## 核心判断

P3 的第一贡献不应被写成“提出若干语义 mutant”，而应是：建立一套用于描述、生成和度量语义变异的形式化体系，并以此重新定义 MR 集合有效性与充分性的评价方式。实验属于该体系的验证，而不是论文的理论中心。

推荐中心论点：

> 传统变异测试以程序语法变换为基本操作，其变异算子与 MR 所表达的语义不变性质之间缺少直接对应关系。P3 建立语义变异的符号体系、核心概念和形式化定义，将变异对象从代码语法结构提升为程序的语义义务，并据此构造面向 MR 集合的有效性与充分性评价方法。

这一命题包含三个层次：

1. **理论贡献**：语义变异的符号体系、概念和定义。
2. **度量贡献**：从语义变异检测结果推导 MR 集合有效性、覆盖性或充分性的指标。
3. **实证贡献**：验证该体系能够实例化，并考察其相对于句法变异是否具有更好的评价能力。

## 建议的论证主线

```text
MR 集合评价的目标
→ MR 表示程序执行之间应保持的语义关系
→ 传统句法变异只改变代码形式或局部运算结构
→ 句法变异算子与 MR 语义义务之间没有必然映射
→ 因而句法变异得分不一定准确反映 MR 集合质量
→ 定义语义义务、语义变异、语义变异体及其检测关系
→ 建立语义变异与 MR 之间的形式化映射
→ 基于该映射定义 MR 集合有效性与充分性
→ 通过配对实验检验其可实施性、区分能力和相对效度
```

“构念不匹配”只能证明提出语义变异具有必要性，不能直接证明语义变异一定更好；“更适合”必须由实验中的评价效度支持。

## 符号体系应成为论文核心

理论部分至少应明确以下对象及其关系：

- 被测程序、输入域及程序语义；
- MR 及 MR 集合；
- MR 对应的语义义务；
- 语义变异算子；
- 语义变异体；
- MR 对语义变异体的检测或杀死关系；
- 语义变异覆盖率；
- MR 集合有效性；
- MR 集合充分性的判定条件。

尤其应避免把“杀死率高”等同于“充分”：

- **有效性**：MR 集合识别预定语义违例的能力。
- **充分性**：MR 集合是否覆盖目标语义义务空间，或继续加入 MR 是否仍能显著增加语义违例检测能力。

P3 因此不是传统 mutation score 的简单替代，而是一套具有明确语义分母和评价对象的度量框架。

## 建议的研究问题

- **RQ1：形式化能力。** 所提出的符号体系能否一致地表达 MR、语义义务及语义变异之间的关系？
- **RQ2：可实施性。** 语义变异能否在真实程序中被构造、执行并由 MR 检测？
- **RQ3：区分效度。** 语义变异指标能否区分质量不同的 MR 集合？
- **RQ4：相对效度。** 与传统句法变异相比，语义变异是否更准确地反映 MR 集合的有效性与充分性？
- **RQ5：外部有效性。** 上述结论能否跨程序、跨语义义务类型成立？

## 当前实验能够支持的结论

目前单项目、4 组配对结果最多支持：

- 语义变异体系可以被实例化；
- 语义变异与配对句法变异并非相同构造；
- 在局部案例中，语义变异表现出额外的区分能力。

它尚不能充分支持“语义变异普遍更适合评价 MR 充分性”。当前结论宜写成：

> 实验结果支持语义变异的可实施性及其与 MR 语义义务之间的构造一致性，并提供了优于句法变异的初步局部证据。

若要得到强结论，还需要比较多个质量已知的 MR 集合，例如完整集、删减集、冗余集和弱化集，并检验两种变异分数谁更能恢复这些质量排序；同时应采用独立或留出的语义变异体，避免根据待评价 MR 直接构造变异体所产生的循环验证。

## 建议的贡献声明

1. 提出语义变异的符号体系及形式化定义；
2. 建立语义变异与 MR 语义义务之间的映射；
3. 提出基于语义变异的 MR 集合有效性与充分性度量；
4. 通过配对实验验证方法的可实施性和初步区分能力；
5. 明确传统句法变异在评价 MR 集合时的构念效度边界。

## 总体定位

P3 当前最稳妥的定位是“形式化理论框架＋初步实证验证”。恢复论文原义不能只修改引言和结论，还应把符号体系提升为全文骨架，并把“语义变异更适合”从先验断言改为需要通过区分效度和准则效度验证的研究命题。
