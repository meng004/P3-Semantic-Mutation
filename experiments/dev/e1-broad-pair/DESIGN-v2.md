# SymPy 认证器数值读取修正（开发运行 v2）

v1 的 `DESIGN.md`、`cert_sympy.py`、日志和 `VERDICT.md` 保持原样；v1 修复后臂的终态仍为 `EXEC_FAIL`。本次只修复原函数端点差的数值读取，不更改四个版本、被积函数、先积分后代入的顺序、区间 `[0,1]`、80 位精度、参考求积或绝对容差 `1e-8`。不运行 MR。

原因：修复后 `endpoint.evalf(80)` 的文本带极小的虚部尾项（v1 异常文本含 `e-86*I`）；v1 把整个复数文本交给仅接收实数的 `mpmath.mpf`，在比较残差前失败。v1 未单独打印虚部数值，本文件不据异常文本断言其精确大小。

本段对虚部大小的措辞在 v2 运行后作了证据精度修正；运行参数、判定规则与脚本未变。

v2 将同一个 `endpoint.evalf(80)` 的实部、虚部分别转换为 `mpmath.mpf`，组成 `mpmath.mpc`，并以其与实数参考求积之差的**复数模**按原绝对容差判定。虚部也计入误差，不截断或忽略；若虚部大到超过容差，仍会判 `CERT_BREAK`。输出实部、虚部、模差及判定。

只重跑 SymPy 修复前与修复后两个臂，日志单独写入 `logs-v2/`。不得用 v2 覆盖 v1 的日志或把 v1 的 `EXEC_FAIL` 改写成 `CERT_HOLD`。即使 v2 区分成功，两个公开缺陷仍只属开发材料，v4 确认性实验仍为 NO-GO。
