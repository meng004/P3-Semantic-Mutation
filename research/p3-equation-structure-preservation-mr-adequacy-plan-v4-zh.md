# 基于方程保结构变异的科学计算程序蜕变关系充分性评价

> 英文题目：Evaluating Metamorphic-Relation Adequacy in Scientific Software Using Equation-Derived Structure-Preservation-Targeted Mutations
>
> 文档性质：P3 理论与实证研究方案（v4）。本文研究固定结构谱系、固定变异池和固定 MR 集合下的静态充分性评价；动态 MR 改进闭环留待下一篇论文。

## 1. 研究定位

科学计算程序通常缺少廉价的逐输入 oracle。蜕变关系（MR）可将方程性质转化为部分测试 oracle，但固定 MR 集合是否充分仍然未知。传统句法变异以代码编辑为评价分母，与 MR 承载的方程保结构语义存在构念错位。本文从方程导出保结构要求，构造并独立认证保结构变异，据此静态评价 MR 集合相对于给定结构谱系的充分性。

本文只回答“如何评价固定 MR 集合”，不研究 MR 的生成、推荐、更新或迭代优化。

## 2. 核心概念

### 2.1 方程导出的保结构要求

**Equation-Derived Structure-Preservation Requirement, ESPR**

定义

\[
r=(\phi,D,\kappa,B,O),
\]

其中，\(\phi\) 为方程蕴含的守恒、对称、单调、伴随、可逆或收敛性质；\(D\) 为适用域；\(\kappa\) 为精确、近似或渐近保持方式；\(B\) 为离散、统计和浮点误差预算；\(O\) 为独立观测与认证方法。若程序在 \(D\) 内按 \(\kappa\) 保持 \(\phi\)，且残差不超过 \(B\)，记为 \(P\models_B r\)。

### 2.2 保结构变异

**Structure-Preservation-Targeted Mutation, SPTM**

保结构变异是以 ESPR 为目标的语义变异：

\[
\mu_{r,\theta}:P\rightarrow P'.
\]

其须满足：接口与可执行性保持；\(P\models_B r\)，而 \(P'\not\models_B r\)；变异已激活且非等价；非目标结构保持在纯性预算内，或明确标记为多标签。认证不得使用 MR 判定器或 kill 结果。

### 2.3 结构谱系相对充分性

**Structure-Lineage-Relative MR Adequacy, SLRMA**

设 \(G\) 为冻结的结构谱系，\(M_g^{neq}\) 为谱系单元 \(g\) 下适用、已认证且非等价的保结构变异体，则 MR 集合 \(R\) 的谱系平衡充分性为

\[
A_G(R)=\frac{1}{|G|}\sum_{g\in G}
\frac{|K_R\cap M_g^{neq}|}{|M_g^{neq}|}.
\]

结果只表示 \(R\) 相对于给定 \(G,D,B\) 和冻结变异总体的充分性，不表示程序正确或绝对充分。NA、构造失败、合法离散破缺及等价未决分别报告。

## 3. 科研逻辑

科学计算 oracle 问题 → 从方程导出保结构要求 → MR 对这些要求建模，但 MR 集合是否充分仍未知 → 句法变异分母与 MR 承载的保结构语义存在构念错位 → 构造保结构变异 → 用 MR 检测结构偏离 → 测量 MR 集合的结构谱系相对充分性。

## 4. 研究贡献

1. **理论贡献**：建立 ESPR、SPTM 和 SLRMA 的统一形式化体系。
2. **方法贡献**：提出共同真理源、MR 与变异独立派生、正交认证、冻结解盲和谱系平衡计分的静态评价方法。
3. **实证贡献**：系统验证该方法的构念效度、判别效度和准则效度，并检验其相对句法变异得分、MR 数量和执行成本的增量信息。

## 5. 研究问题

- **RQ1 构念效度**：ESPR 能否被操作化为可认证的 SPTM，并比预算匹配的一阶和高阶句法变异更集中地产生预声明结构偏离？
- **RQ2 判别效度**：SLRMA 能否恢复完整、删族、弱化、冗余和错配 MR 集合的预注册质量偏序？
- **RQ3 准则效度**：SLRMA 能否解释独立真实缺陷的 MR 检出结果，并提供超出句法变异得分、MR 数量和执行成本的增量信息？
