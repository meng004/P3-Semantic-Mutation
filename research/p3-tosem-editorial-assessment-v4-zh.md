# P3 v4：ACM TOSEM 编辑视角评估

> 评估对象：当前 `source/main.tex` 与 `research/p3-equation-structure-preservation-mr-adequacy-plan-v4-zh.md`。
>
> 评估边界：本文档是只读投稿评估，不修改 manuscript。

## 总体判断

新方案具有较强的 TOSEM 选题契合度和原创潜力，但当前 `main.tex` 尚不适合直接投稿。若以现稿投稿，较可能是“拒稿后重构再投”，而不是常规大修；原因不是选题弱，而是论文身份、理论构念和确认性证据尚未统一。

| 维度 | 当前 `main.tex` | 按 v4 完成后 |
| --- | --- | --- |
| 期刊契合度 | 高 | 高 |
| 概念原创性 | 中等偏高，但被复杂叙事稀释 | 高 |
| 理论成熟度 | 中等偏低 | 可达中高 |
| 构念效度 | 偏弱 | 取决于 RQ1 |
| 测量判别力 | 尚未证明 | 取决于核心 RQ2 |
| 外部效度 | 有探索证据 | 取决于独立缺陷队列 |
| 表达清晰度 | 偏低 | 明显改善 |
| 当前投稿成熟度 | 低 | 完成新实验后可具竞争力 |

## 编辑最可能认可的贡献

### 1. 新的充分性评价对象

最有价值的不是再提出一个 Mutation Score，而是把 MR 充分性的评价对象定义为：

> MR 集合对方程保结构要求谱系的覆盖能力。

这使充分性的分母从一般代码编辑转向科学计算程序真正关心的结构风险，是最核心的理论创新。

### 2. MR 与变异体独立派生和认证

共同真理源、角色隔离、正交认证和冻结解盲，直接回应最危险的循环论证：

> 不能用某个 MR 定义语义变异体，再以该 MR 能否杀死它来证明 MR 有效。

如果严格实现，这会成为 TOSEM 编辑认可的方法严谨性贡献。

### 3. 测量效度验证框架

RQ1—RQ3 分别检验构念效度、判别效度和准则效度，比当前按多个实验臂并列的组织方式清楚得多。其中 RQ2 最关键：

> 如果 SLRMA 不能恢复质量已知 MR 集合的预注册偏序，就不能证明它在测量充分性。

## 当前 `main.tex` 可利用的内容

以下内容可迁移到新论文：

- SMS 的经典比例形式和 effect-fiber 思想，可作为 SLRMA 的技术基础；
- detection-window、interval 和 gap 等结果，可支持误差预算及合法离散破缺；
- 5.14% AST 重叠可作为句法分母错位的 pilot 证据，但不能支持普遍结论；
- \(\xi=0.765\) 可作为“生成标签不足以认证语义效应”的反面证据；
- 强/弱 MR 边界案例可解释容差、误报与漏报；
- 伴随算子实验最适合升级为正交认证实例；
- claim–evidence map、推断许可表和明确非主张应完整保留；
- 当前 60-cell 数据可作为 development/pilot set，不能继续作为新理论的确认性数据。

## 接收前的主要阻塞

### 1. 现稿与新方案不是同一篇论文

当前稿件以 CE/OS/HP/TF/SI 五类经验算子、SMS、LRCA 和多条扩展证据为中心；v4 则以 ESPR、SPTM 和 SLRMA 为中心。这不是术语替换，而是研究对象和效度逻辑的重构。正文需要按新标题和三个 RQ 重新组织。

### 2. “结构谱系”尚未真正建立

必须明确：

- 谱系节点是什么；
- 父子或派生关系是什么；
- 哪些性质只是并列结构族；
- 多标签变异如何计分；
- NA、合法离散破缺和等价未决如何影响分母；
- 谱系不平衡为何采用宏平均，以及替代聚合结果是否稳健。

如果只是把五类算子重新命名为结构谱系，TOSEM 审稿人会认为贡献仍是经验分类。

### 3. 独立认证必须成为可执行机制

当前 E1/E2 主要检查运行一致性和采样等价，不足以认证方程结构偏离。至少需要若干真正正交的认证器，例如：

- 守恒：源—汇—边界平衡；
- 对称：离散算子交换子；
- 伴随：双线性恒等式；
- 可逆：往返状态残差；
- 收敛：独立网格序列和误差阶。

### 4. 必须新增确认性实验

不能在旧 60-cell 数据上重新定义理论后继续检验。建议：

- 旧对象作为开发集；
- 新方程和独立求解器作为冻结确认集；
- RQ1 加入预算匹配 FOM/HOM；
- RQ2 使用完整、删族、弱化、冗余和错配 MR 集合；
- RQ3 使用不按 MR 可检测性筛选的真实缺陷；
- 以程序或求解器为统计单位，而非把变异体和输入当作独立样本。

### 5. 现稿需要显著删减

建议从主线移出或降入附录：

- LLM 来源效应；
- Pattern Coverage 相关性；
- 大量部署、标准和 air-gap 讨论；
- 不能支撑主结论的 Friedman 及多重次级分析；
- 选择条件工业臂的详细展开；
- 把退化定理作为主要创新的叙述。

正文只围绕三个 RQ 组织结果。

## 最终编辑建议

- **当前 `main.tex`：不建议直接投 TOSEM。**
- **v4 方案：值得作为 TOSEM 目标版本推进。**
- **决定性实验：RQ2 的 MR 质量梯度恢复。**
- **决定性理论要求：ESPR 与 SPTM 之间存在可执行、独立于 MR 的认证关系。**
- **决定性外部证据：独立准入的真实缺陷，而非预先验证可被 MR 检测的缺陷。**

把静态评价留在 P3、把动态“评价—诊断—改进—再评价”留给下一篇，是正确的范围切分。这样 P3 回答“如何可信地测量 MR 充分性”，下一篇回答“如何利用测量结果持续改进蜕变测试”，两篇论文的研究对象和创新边界都更清楚。
